Справочник каталога DCS API#

Каждая строка: функция DCS, которую можно вызвать через ctx.dcs() (Rust) или Dcs(client) (Python), её обёртка, аргументы и результат в нотации каталога, класс (определяет полосу и включён ли вызов по умолчанию) и проверка на живом DCS. Как пользоваться вызовами, описано на странице Вызовы DCS.

Классы: read — включено по умолчанию (кроме функций, отмеченных как «проба»: они выключены, пока их проверка не прошла на текущей сборке DCS); heavy — дорогое чтение: по одному, не чаще 2 в секунду на писателя, со своим бюджетом времени DCS (dcs_time.heavy, лимиты); mutate — меняет мир, выключено, пока владелец движка не включит его в engine.toml (или sortied --dev); admin — администрирование сервера.

Проверка span_300km в описании записи: концы вызова не дальше 300 км друг от друга по карте (север и восток), иначе Error::Invalid, и в DCS ничего не уходит.

Вызовы DCS — API ревизии 1: логика объявляет #[sortie::mission(api_rev = 1)]. Запись, у которой в столбце «Класс» стоит «ревизия API N», требует от своей обёртки в ctx.dcs() api_rev = N (иначе Error::Revision) и движка этой ревизии (иначе Error::EngineTooOld). Это проверка SDK, а не движка. Вызов по имени (ctx.dcs().call(..), фича dcs-raw) и вызов из Python идут с ревизией 1: движок ревизии N и новее их выполнит, а более старый не знает такой записи и отвечает Error::Rejected (в Python — REJECTED).

Записи sortie.* — функции не DCS, а Lua-слоя Sortie: слой выполняет их внутри DCS в том же кадре поверх функций DCS, которые вызывает сам (sortie.findPathOnRoads — сводка пути по дорогам и не больше заданного числа его точек). Им нужен Lua-слой той версии SDK, что их добавила (sortie install); более старый слой отвечает MISSING (Error::Unavailable).
