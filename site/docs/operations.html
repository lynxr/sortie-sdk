Эксплуатация#

Где что лежит#

Всё, что ставит и пишет Sortie, лежит в папке Saved Games экземпляра DCS: %USERPROFILE%\Saved Games\DCS, а для --instance server — Saved Games\DCS.server.

ПутьЧто
Scripts\Sortie\sortie-mission.lua, Scripts\Sortie\layer\Lua-слой моста
Scripts\Sortie\bin\sortie_bridge-<версия>.dllDLL моста; версия в имени, потому что загруженную DLL Windows перезаписать не даст
Scripts\Sortie\pending.txt, active.txtкакую DLL загрузить; при старте DCS pending становится active
Scripts\Hooks\sortie-hook.luaхук: загружает мост в среду hooks DCS
Sortie\link.secretобщий секрет моста и движка
Sortie\link.addrадрес, на котором слушает sortied; мост читает его перед каждым подключением
Sortie\tokens.tomlтокены API
Sortie\sortie.dbхранилище движка: сборки, состояние, итоги
Sortie\Logs\логи sortied
Logs\sortie-bridge.logлог моста
Missions\Sortie\зарегистрированные сборки: <сценарий>-<build_id>.miz

В папке DCS Sortie меняет одну строку в Scripts\MissionScripting.lua. Больше ничего в установке DCS не трогается.

sortied#

sortied [--instance <имя>] [--saved-games <папка>] [--dcs <папка DCS>]
        [--api 127.0.0.1:50777] [--link pipe:<имя> | tcp:<host:port>]
        [--db <файл> | memory] [--tokens <файл>] [--manifest <файл.manifest.pb>]
        [--dev] [--dev-eval] [--log-dir <папка> | none]
ФлагПеременнаяЧто делает
--instanceSORTIE_INSTANCEэкземпляр DCS; то же имя, что у sortie install
--saved-gamesSORTIE_SAVED_GAMESпапка Saved Games экземпляра
--dcsSORTIE_DCSпапка DCS для проверок doctor при старте
--apiSORTIE_APIадрес API; держите его на 127.0.0.1: API управляет сервером
--linkSORTIE_LINKгде ждать мост; по умолчанию именованный канал экземпляра
--dbSORTIE_DBфайл хранилища; memory — без файла, для экспериментов
--tokensSORTIE_TOKENSфайл токенов вместо Sortie\tokens.toml
--manifestSORTIE_MANIFESTmanifest для миссии, которую не регистрировали (собрана build и открыта вручную)
--devлокальные программы работают без токена; спавн и уничтожение в логике — только с .key(..)
--dev-evalразрешить отладочные команды DevEval (только роль admin)
--log-dirSORTIE_LOG_DIRпапка логов; none — только консоль

Подробность логов задаёт SORTIE_LOG (по умолчанию info), например SORTIE_LOG=debug.

Токены#

# Saved Games\DCS\Sortie\tokens.toml
[[token]]
name = "my_mission logic"
role = "logic"          # admin | logic | generator | observer
token = "6f1c..."       # клиент шлёт заголовок `authorization: Bearer <token>`
РольЧто можно
observerчитать: версии, здоровье, мир, события, состояние, итоги
logicплюс подключать логику и отдавать команды, писать состояние
generatorрегистрировать и запускать сборки, перезапускать миссию, писать состояние
adminвсё

sortie install создаёт токены ролей admin и logic. Токен generator добавьте сами, если не хотите отдавать генератору admin; токен — любая длинная случайная строка. sortied читает файл при старте.

  • Логика берёт токен из SORTIE_TOKEN.
  • Генератор — из --token или SORTIE_TOKEN.
  • sortie status, events, top — из --token, SORTIE_TOKEN или сами из tokens.toml.

С sortied --dev программы на той же машине работают без токена.

Dedicated server#

Dedicated server с Sortie ещё не проверялся в живой игре. Ниже — как он должен работать.

  • Сервер запускается с -w DCS.<имя> и пишет в Saved Games\DCS.<имя>. Передайте то же имя всем командам: sortie install --instance <имя>, sortie doctor --instance <имя>, sortied --instance <имя>. Мост берёт имя экземпляра из своей папки сам.

  • Если DCS World Server стоит рядом с игрой, укажите его папку явно:

    .\bin\sortie.exe install --instance server --dcs "C:\Program Files\Eagle Dynamics\DCS World Server"
.\bin\sortie.exe doctor --instance server --dcs "C:\Program Files\Eagle Dynamics\DCS World Server"
.\bin\sortied.exe --instance server

  • С пустым списком миссий сервер не стартует. Положите в список миссию-заглушку: в ней нет юнитов, только сообщение о том, загружен ли мост. doctor проверяет, что список не пустой.

    uv run sortie-gen lobby --out sortie-lobby.miz

  • python scenario.py launch регистрирует сборку и просит движок загрузить её в DCS. python scenario.py restart перезагружает текущую миссию: сессия кончается с причиной restart, начинается новая, логика получает Start::Restart.

  • На паузе скрипты миссии не выполняются. Команды логики ждут конца паузы, если не задано .on_pause(Fail). Проверка типов на сервере, который стоит на паузе без игроков, не пройдёт: генератор предупредит и зарегистрирует сборку без неё.

  • Перезапуска DCS после краша или зависания Sortie пока не делает. Если на машине есть DCSServerBot, эту работу делает он.

Наблюдение#

Общие флаги утилиты: --instance, --saved-games, --dcs, --api, --token.

Обновление#

Рантайм. Распакуйте новый архив рядом со старым и выполните из новой папки .\bin\sortie.exe install. Новая DLL ляжет рядом со старой, а запущенная DCS продолжит работать со старой. Перезапустите DCS: при старте она возьмёт новую DLL и новую часть Lua-слоя для hooks. sortie doctor подтвердит версию. Перезапустите и sortied.

SDK. Поменяйте тег в Cargo.toml и pyproject.toml (см. Подключение SDK), пересоберите логику и зарегистрируйте новую сборку. Версии SDK и рантайма должны совпадать.

DCS. Обновление DCS перезаписывает MissionScripting.lua и стирает строку Sortie. Тогда мост не загрузится в миссию, и на экране будет «Sortie bridge is not installed: run sortie doctor». После каждого обновления DCS запускайте sortie doctor; если строка пропала — sortie doctor --fix от имени администратора.
