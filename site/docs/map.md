# Рисование на карте

`ctx.map()` рисует на карте F10: метки с текстом, линии, ломаные, многоугольники, круги,
прямоугольники, стрелки и надписи. Каждый рисунок — именованный ресурс сессии: движок помнит
его, показывает в реплике мира (`ctx.world().resources()`) и убирает, когда сессия кончается.
Повторная команда с тем же именем не рисует второй рисунок, а приводит существующий к новому
описанию.

## Ревизия API

Рисунки — API ревизии 1. Событие `ResourceEnded` (рисунок исчез не по команде логики) — событий
ревизии 1; без `event_rev = 1` логика его не получает.

```rust
#[sortie::mission(api_rev = 1, event_rev = 1)] // рисунки — API ревизии 1, их концы — событий 1
pub async fn with_drawings(ctx: Ctx<MyMission>, _start: Start) -> sortie::Result<()> {
    let target = zones::TARGET.center();
    ctx.map()
        .circle("zones/target", target, 3_000.0)
        .color(Rgba::RED)
        .fill(Rgba::RED.alpha(0.15))
        .line_style(LineStyle::Dashed)
        .to(Coalition::Blue)
        .await?;
    ctx.end_session(Outcome::Draw).await
}
```

## Фигуры

| Метод | Что в DCS |
| --- | --- |
| `panel(имя, место, текст)` | метка с текстом (`markToAll` / `markToCoalition` / `markToGroup`) |
| `line(имя, a, b)` | одна линия |
| `path(имя, точки)` | ломаная из 2..=33 точек: по линии DCS на отрезок |
| `polygon(имя, точки)` | замкнутая фигура из 3..=64 точек (4 точки — четырёхугольник DCS) |
| `circle(имя, центр, радиус_м)` | круг |
| `rect(имя, a, b)` | прямоугольник по двум противоположным углам |
| `arrow(имя, остриё, хвост)` | стрелка |
| `text(имя, точка, текст)` | надпись на карте, масштабируется вместе с картой |

```rust
let map = ctx.map();
map.line("front/1", a, b).color(Rgba::RED).await?;
map.path("route", [a, target, b])
    .to(Coalition::Blue)
    .await?; // 2 линии DCS
map.polygon("area", [a, target, b])
    .fill(Rgba::GREEN.alpha(0.2))
    .await?;
map.rect("strip", a, b).await?;
map.arrow("push", target, a).await?; // остриё в target
map.text("label", b, "FLOT").font_size(24).await?;
map.panel("rally", target, "Сбор здесь")
    .editable() // игроки могут менять и удалять
    .announce("Новая точка сбора")
    .await?;
```

Настройки: `.color(Rgba)` — цвет линии и текста (по умолчанию цвет коалиции, белый для всех),
`.fill(Rgba)` — заливка (по умолчанию нет), `.line_style(LineStyle)` — тип линии (по умолчанию
сплошная), `.to(..)` — кто видит (можно несколько раз, до 8; без `.to` — все), `.editable()` —
игроки могут менять и удалять, `.announce(текст)` — сообщение аудитории при появлении,
`.font_size(n)` — размер надписи, `.ttl(время)` — срок жизни. Фигуры видны всем или одной
коалиции; одной группе — только метка с текстом (`panel`). Остальные аудитории —
`Error::Invalid`.

## Изменения

Движок сравнивает новое описание с зарегистрированным:

| Результат (`Drawn.change`) | Когда | Вызовы DCS |
| --- | --- | --- |
| `Created` | имени ещё нет | по одному на метку |
| `Unchanged` | описание то же | ни одного |
| `Updated` | изменились цвет, заливка, радиус круга, текст или размер надписи, первая или последняя точка; или только `ttl` / `announce` | по одному на изменённое свойство метки; id меток те же |
| `Replaced` | всё остальное: тип линии, средняя точка, число точек, текст или место метки, аудитория, `editable` | новые метки, затем удаление старых |

```rust
let zone = |r: f64| {
    ctx.map()
        .circle("zones/target", target, r)
        .color(Rgba::RED)
        .to(Coalition::Blue)
};
let d = zone(3_000.0).await?;
assert_eq!(d.change, Change::Created);
let d = zone(3_000.0).await?; // тот же спек: в DCS ничего не уходит
assert_eq!((d.change, d.dcs_calls), (Change::Unchanged, 0));
let d = zone(5_000.0).await?; // радиус меняется на месте, id метки тот же
assert_eq!(d.change, Change::Updated);
// Временная метка: исчезнет через 2 минуты модельного времени.
ctx.map()
    .text("hint", target, "Цель накрыта")
    .ttl(Duration::from_secs(120))
    .await?;
```

Команды над одним именем выполняются в порядке отправки, даже если первая ещё не дошла до DCS;
команды над разными именами друг друга не ждут. `.key(..)` не нужен: повтор команды — та же
команда.

## Удаление и концы

`remove(имя)` удаляет рисунок (нет такого — `Change::Absent`), `remove_prefix("zones/")` — все
свои рисунки с этим началом имени, `clear()` — все свои. Чужой рисунок (другой логики или
токена) удаляется только с `.any_owner()`; его владелец получит `ResourceEnded` с причиной
`REMOVED_BY_OTHER`.

Рисунок кончается и без команды: истёк `ttl` (`EXPIRED`), игрок удалил редактируемую метку
(`PLAYER`; копии для других аудиторий движок удаляет сам), после обрыва связи с DCS рисунка не
оказалось (`LOST`). Если игрок отредактировал метку, ресурс помечается `drifted`, и следующая
команда с тем же именем нарисует его заново.

```rust
let mut ends = ctx.events().of::<v1::ResourceEnded>();
let mut deleted_by_players = Vec::new();
while let Some(e) = ends.next().await {
    if e.reason == v1::ResourceEndReason::Player as i32 {
        deleted_by_players.push(e.name); // игрок удалил редактируемую метку
    }
}
// Что зарегистрировано сейчас: реплика мира.
let n = ctx.world().resources().count();
ctx.map().remove_prefix("zones/").await?;
ctx.map().clear().await?; // все рисунки этой логики
```

У событий `Mark` по зарегистрированным рисункам заполнены `name` (имя рисунка) и `own` (`true`,
если событие вызвал сам Sortie: DCS, по описаниям сообщества, повторяет метки скриптов
событиями; на сервере это ещё не проверено).

## Ограничения

* Id меток DCS общие у игроков, скриптов и Sortie. Sortie берёт id от 7 100 000 и никогда не
  повторяет их в одной миссии; сырые вызовы `trigger.action.markToAll` и др. через `ctx.dcs()`
  с id от 7 100 000 отклоняются.
* DCS не умеет перечислять фигуры на карте: после перезапуска движка, пока миссия идёт, Sortie
  удаляет рисунки прежнего движка и продолжает нумерацию выше них.
* `setMarkupTypeLine` DCS не передаёт клиентам, поэтому смена типа линии перерисовывает фигуру.
* Что из этого подтверждено на сервере DCS 2.9.31, а что ещё нет, — в
  [справочнике каталога](dcs-catalog.md) (проверки TRG-L9, TRG-L10, TRG-L17).
