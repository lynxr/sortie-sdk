Для агентов#

ИИ-агенты (Claude Code и другие) пишут логику и сценарии Sortie лучше, когда знают API и правила SDK. Для этого в SDK есть навыки (skills) и файл AGENTS.md. Они написаны на английском: так их лучше понимают агенты.

Навыки#

Скачать архив навыков (sortie-agent-skills-0.1.0.zip). Те же файлы лежат в репозитории SDK, в папке agents/.

  • sortie-live-debugging sortie-live-debugging/Sortie in a live DCS World: install and `sortie doctor`, `sortied --dev`, attaching the mission and the logic, reading dcs.log, the sortied log, sortie-bridge.log and the logic's stderr. Use when a Sortie mission does not attach or misbehaves in DCS, when the DCS screen shows a "Sortie ..." message, after installing or updating Sortie or DCS, when players cannot take multiplayer slots, after a Mission Editor round trip, or when an error mentions the bridge, the engine, a session or a token.
  • sortie-mission-logic sortie-mission-logic/Sortie mission logic in Rust (crate `sortie`, DCS World). Use when writing or changing a `#[sortie::mission]` or code that uses `Ctx` (commands, `.key()`, `ctx.once`, waits, events, F10 menus, flags, state, timers, `end_session`), when handling `Start` kinds, when a `sortie::*` error code appears (`sortie::gone`, `sortie::invalid`, `sortie::unknown_symbol`, ...), or when designing a long multiplayer mission. Applies to any crate that depends on `sortie` or calls `sortie::include_scenario!`.
  • sortie-scenario sortie-scenario/Sortie scenarios in Python (`scenario.py` with sortie-gen over pydcs, DCS World). Use when writing or changing a scenario (zones, ground groups, air templates, statics or other pydcs content, airbases, player flights and their airfield coalition, flags, F10 menus), when running `lock`, `build`, `validate`, `register`, `launch`, `restart`, `watch` or `results`, when a sortie-gen error or warning appears, or when the Rust logic needs a new symbol.

Как подключить к Claude Code#

  1. Распакуйте архив.
  2. Скопируйте папки навыков (в каждой есть SKILL.md, пути указаны в списке выше) в папку .claude/skills/ вашего проекта. Чтобы навыки работали во всех проектах, положите их в ~/.claude/skills/.
  3. Положите AGENTS.md в корень проекта. Claude Code читает CLAUDE.md, поэтому добавьте в него строку @AGENTS.md: так он подключит и этот файл.
  4. Начните новую сессию Claude Code. Навык подключается сам, когда задача подходит под его описание.

Другие агенты#

AGENTS.md в корне проекта читают многие агенты. Навыки — обычные файлы Markdown: их можно передать любому агенту как контекст.
