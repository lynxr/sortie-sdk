Загрузки#

Версия 0.1.0, тег v0.1.0. Все файлы выпуска есть на странице релиза.

SDK для логики на Rust#

Исходники SDK, документация, шаблон миссии и пример op_north лежат в репозитории github.com/lynxr/sortie-sdk. Скачивать SDK отдельно не нужно: cargo возьмёт его из git по тегу.

[dependencies]
sortie = { git = "https://github.com/lynxr/sortie-sdk", tag = "v0.1.0" }

[build-dependencies]
sortie-build = { git = "https://github.com/lynxr/sortie-sdk", tag = "v0.1.0" }

Генератор миссий на Python#

Добавьте генератор в свой uv-проект прямо из репозитория:

uv add "sortie-gen @ git+https://github.com/lynxr/sortie-sdk@v0.1.0#subdirectory=python/sortie-gen"

Или скачайте колесо sortie_gen-0.1.0-py3-none-any.whl из таблицы ниже и установите его из файла:

uv add ./sortie_gen-0.1.0-py3-none-any.whl

Рантайм для Windows#

Архив рантайма содержит движок sortied.exe, CLI sortie.exe, DLL моста и Lua-слой. Как установить его в DCS, написано в быстром старте и в README внутри архива.

ФайлЧто в нём
sortie-runtime-0.1.0-win64.zipрантайм: движок, CLI, мост и Lua-слой
sortie_gen-0.1.0-py3-none-any.whlгенератор миссий, колесо Python
SHA256SUMSконтрольные суммы файлов выпуска

Проверить скачанный архив в PowerShell:

Get-FileHash .\sortie-runtime-0.1.0-win64.zip -Algorithm SHA256

Хэш должен совпасть со строкой этого файла в SHA256SUMS (регистр букв не важен).

Закрытый репозиторий#

Если репозиторий SDK закрыт, cargo и uv скачивают его через git с вашими учётными данными GitHub. Cargo для этого должен звать git из командной строки:

# %USERPROFILE%\.cargo\config.toml
[net]
git-fetch-with-cli = true

Сам git должен уметь читать репозиторий, например через Git Credential Manager из Git for Windows. Файлы релиза закрытого репозитория скачивайте со страницы релиза, войдя в GitHub. Подробности — в документации.

Локальная сборка#

Если вы открыли сайт из папки dist/ локальной сборки, архивы лежат рядом с ним: SDK и рантайм.
