Sortie Миссии для DCS World: логика на Rust, сценарий на Python

Sortie — внешний движок миссий для DCS World. Поведение миссии — обычная асинхронная программа на Rust, которая работает рядом с игрой, а не внутри неё. Сама миссия собирается на Python. В DCS остаётся только тонкий мост.

Быстрый стартЗагрузкиДокументация

Как это устроено

  1. Сценарий. На Python с генератором sortie-gen (поверх pydcs) вы описываете карту, время, группы, зоны, флаги, команды F10-меню и слоты игроков. Генератор собирает .miz, manifest и scenario.lock.json.
  2. Логика. Крейт на Rust с SDK sortie. Из lock-файла sortie-build делает типизированные символы сценария, поэтому опечатка в имени группы или зоны — это ошибка компиляции, а не сбой посреди миссии.
  3. Регистрация. Генератор отдаёт миссию движку sortied, и тот кладёт её в папку миссий DCS.
  4. Игра. Мост передаёт движку события и состояние мира и выполняет его команды. Логика читает мир из локальной копии и получает результат каждой команды из DCS.

Что умеет SDK

Сценарий в типах
Группы, зоны, шаблоны, флаги, аэродромы и команды меню из сценария становятся константами Rust. Группа чужого сценария или приказ не того типа не скомпилируются.
Команды с ответом
Сообщения, дым, флаги, F10-меню, спавн по шаблону, опции и задачи ИИ. Каждая команда возвращает результат из DCS, а .key() не даст выполнить её дважды после переподключения.
Ожидание по времени и миру
ctx.sleep, ctx.timer (таймер хранится в движке), ctx.wait_until с условием на мир и потоки событий.
Состояние и итог
Документ кампании ctx.state, действия один раз за сессию или за ход, отчёт и исход сессии.
Логика вне игры
Логика — отдельный процесс. Если она упала, её можно запустить снова, не перезапуская миссию.
Миссия из кода
Генератор проверяет имена при сборке и через движок регистрирует, запускает и перезапускает миссию, а потом забирает результаты.

Что нужно

  • Windows 10 или 11 (x64) с DCS World 2.9 или DCS World Server.
  • Рантайм Sortie: архив sortie-runtime-0.1.0-win64.zip с движком sortied, CLI sortie, мостом и Lua-слоем (загрузки).
  • Rust 1.89 или новее. На Windows нужны инструменты сборки MSVC.
  • Python 3.11 или новее и uv для генератора.
  • Доступ к репозиторию SDK на GitHub: github.com/lynxr/sortie-sdk.

В версии 0.1.0 нет тестов логики без DCS: они появятся в SDK 0.2.
