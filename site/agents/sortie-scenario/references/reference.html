sortie-gen reference (for agents)#

from sortie_gen import Scenario, StartType, Coalition. Unit and aircraft types are pydcs classes (dcs.vehicles.*, dcs.planes.*, dcs.helicopters.*); countries are pydcs country names ("Russia", "USA"); airbases are names of the map's airports ("Krymsk") or sc.theatre.airports[..]. Unknown names fail with a "did you mean" hint.

Idents are optional for zones and ground groups (no ident: no Rust symbol) and required for templates, airbases, flags and menus.

python scenario.py flags#

lock      [--out FILE] [--check]
build     [--out DIR] [--lock FILE] [--locked] [--build-id ULID] [--stem NAME] [--no-miz]
validate  [--engine ADDR] [--token T] [--timeout S]
register  [--out DIR] [--lock FILE] [--locked] [--no-validate] [--engine ADDR] [--token T] [--timeout S]
launch    [--build-id ID] [--out DIR] [--lock FILE] [--locked] [--no-validate] [--engine ADDR] [--token T] [--timeout S]
restart   [--engine ADDR] [--token T] [--timeout S]
watch     [--session S] [--kinds birth,dead,...] [--from-seq N] [--engine ADDR] [--token T] [--timeout S]
results   [--session S] [--json] [--engine ADDR] [--token T] [--timeout S]
  • --timeout: seconds per engine call (default 15).
  • watch --kinds: birth, dead, unit_lost, kill, hit, shot, takeoff, land, base_captured, mark, player_entered_unit, unit_gone, menu_pressed, player_connected, player_disconnected, player_changed_slot, chat_message, simulation_paused, simulation_resumed, gap, unknown.
  • build --no-miz --stem NAME --out DIR writes only the manifest files.
  • launch --build-id ID builds and checks nothing: it loads a build registered earlier.

sortie-gen#

sortie-gen lock|build|validate|register|launch <scenario.py> [flags]
sortie-gen restart|watch|results [flags]                 # no scenario file needed
sortie-gen lobby [--out missions/sortie-lobby.miz] [--theatre caucasus]
sortie-gen adopt my.miz [--json]
  • lobby writes the idle mission for a dedicated server's missionList (no units, no bootstrap; it shows whether the bridge loaded). The engine uses the running lobby to check types.
  • adopt reports an editor mission: groups, units, zones, proposed idents, names that break the rules. pydcs may move aircraft to other parking spots when it saves a mission: place player slots with player_flight.
  • worker (the campaign loop) is not available yet: it exits with code 2.

Errors and warnings#

The CLI prints error: ... without a traceback. In code they are sortie_gen exceptions: InvalidName, NameConflict, ScenarioError, LockError, UnknownTypes, EngineError, EngineUnavailable, EngineNotReady, NotYet (all GeneratorError).
