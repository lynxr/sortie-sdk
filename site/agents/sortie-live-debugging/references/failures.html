Failure signatures (for agents)#

Symptom first. Check the links of the chain in this order: DCS screen and dcs.log, then sortie status, then the sortied console, then the logic's stderr.

SymptomCauseFix

dcs.log: Sortie: Scripts/Sortie/active.txt is missing: run `sortie install` no bridge installed in this Saved Games folder (or another instance)sortie install with the right --instance, restart DCS
screen: Sortie: build <id> (<scenario>) is not registered with this engine; register it with `sortie-gen register` ...the .miz came from an offline build, or the engine's database is another one (--db memory forgets on restart)scenario.py register and open the registered copy from Missions\Sortie, or start sortied --manifest dist\<id>.manifest.pb
screen: Sortie: the mission's digest ... does not match build ...the .miz was changed after the build or belongs to another buildbuild and register again; edit scenario.py, not the .miz
screen: Sortie: the mission says scenario ... / ... schema ...the bootstrap and the registered build disagreerebuild and register
nothing on screen; sortie status: link mission: down, note no mission link: no Sortie mission is runningsortied is not running, the mission has not started, or the link points elsewherestart sortied; same --instance for install, doctor and sortied; dcs.log: mission link down: <error>; retrying names the reason

SymptomCauseFix

sortie::rejected: "rate limit: the heavy calls of (writer) cost more than 20 ms of DCS time per second (dcs_time.heavy ...); the next one may go in N s"a heavy call (a long road path) took more DCS time than the writer's heavy budget holds (200 ms, refilled 20 ms a second); reads are not heldwait the N s before the next heavy call; ask a road path once per route; ends further apart cost more (at most 300 km)
sortie::rejected: "rate limit: the reads of (writer) cost more than 20 ms of DCS time per second"a read or a batch (any batch, a mutate in it too) cost more DCS time than the read budget; since 0.4.0 a single read waits at most 1 s, a batch until the whole debt is paid backretry after e.retry_after(); split big batches and spread them; a costly read belongs to class heavy
