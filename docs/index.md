# Sortie SDK

Sortie — внешний движок миссий для DCS World. Поведение миссии пишется на Rust и работает в
отдельном процессе рядом с DCS. Статическая часть миссии описывается на Python и собирается в
обычный `.miz`.

Это SDK версии 0.1.0: библиотеки для логики на Rust, генератор миссий на Python,
шаблон проекта и документация. Движок и мост для DCS поставляются отдельно, готовым архивом
рантайма.

## Как это устроено

```text
 DCS World ── мост (DLL + Lua) ──▶ sortied ◀── логика миссии (Rust, крейт sortie)
                                      ▲
                                      └─────── генератор sortie-gen (Python): сборка и запуск миссий
```

| Часть | Что делает | Откуда |
| --- | --- | --- |
| мост | DLL и Lua-слой внутри DCS. Передаёт движку события и состояние мира, выполняет команды | архив рантайма |
| `sortied` | движок. Держит зеркало мира, планирует команды в DCS, хранит состояние и итоги | архив рантайма |
| `sortie` | утилита: установка в DCS, проверка установки, наблюдение за движком | архив рантайма |
| логика | ваша программа на Rust с крейтом `sortie`: что происходит в миссии | этот SDK |
| сценарий | ваш файл на Python с пакетом `sortie-gen`: карта, группы, зоны, слоты игроков | этот SDK |

Сценарий описывает, что стоит на карте. Генератор собирает из него `.miz` и файл
`scenario.lock.json` с именами групп, зон и других объектов. Из этого файла логика получает
типизированные константы: опечатка в имени группы ломает сборку логики, а не миссию в игре.

При старте миссии DCS вызывает мост, мост подключается к `sortied`, и движок начинает сессию.
Логика получает сессию и работает с миром. Чтение мира синхронное и локальное, без задержек.
Каждая команда в DCS — это `async`-вызов, который завершается, когда DCS её выполнила.

## Что можно делать

* ждать условий: «синие в зоне», «от группы никого не осталось», таймер модельного времени;
* читать мир: юниты, группы, игроки, зоны, расстояния;
* отдавать команды: сообщения, дым, флаги, опции ИИ, задачи авиации, спавн групп из шаблонов,
  уничтожение групп;
* добавлять команды в меню F10, общие для коалиции или свои у каждой группы;
* обрабатывать события: гибель, попадания, взлёты, вход игроков в слоты;
* хранить состояние миссии и кампании в движке;
* собирать миссии воспроизводимо: офлайн-сборка одного и того же сценария даёт побайтно тот же
  `.miz`;
* проверять имена, типы юнитов и правила DCS до запуска миссии;
* перезапускать миссию и смотреть итоги сессии.

## Требования

* Windows 10 или 11, x64.
* DCS World. Проверена версия 2.9.31. Для сервера — DCS World Server.
* Rust stable не ниже 1.89 ([rustup](https://rustup.rs)). На Windows Rust нужен линкер MSVC:
  Visual Studio Build Tools с компонентом «Desktop development with C++».
* [uv](https://docs.astral.sh/uv/) для генератора. Python 3.11 или новее uv поставит сам.
* Git: cargo и uv берут SDK из Git-репозитория.
* Права администратора один раз, при установке рантайма.

Логику и сценарий можно собирать и на Linux. Рантайм (`sortied`, мост) работает только на
Windows рядом с DCS.

## Состояние версии 0.1.0

* В живом DCS 2.9.31 проверены одиночная игра и сетевая игра, где хост — обычный клиент DCS.
* На dedicated server Sortie ещё не запускался. Перезапуск миссии (`restart`), запуск сборки
  движком (`launch`) и проверка типов (`validate`) покрыты тестами, но в живой игре не
  проверялись.
* Тестов без DCS в этой версии нет: они появятся в SDK 0.2. Подробнее — в
  [Тестировании](testing.md).

Полный список ограничений — в разделе [Вопросы и ограничения](faq.md).
