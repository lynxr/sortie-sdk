## 0.1.0

Первый выпуск SDK для авторов миссий.

* Крейт `sortie`: функция миссии `#[sortie::mission]`, программа `sortie::main!`, контекст
  `Ctx`, команды с ключами идемпотентности, ожидание по времени и состоянию мира, события, меню
  F10, флаги, спавн из шаблонов, задачи авиации, состояние сессии, хода и кампании, итоги
  сессии, ошибки с местом в коде.
* Крейт `sortie-build`: символы сценария из `scenario.lock.json` для `build.rs`.
* Генератор `sortie-gen`: сценарий на pydcs, воспроизводимая сборка `.miz` и manifest, lock,
  правило аэродрома игроков, проверка типов через запущенную DCS, регистрация, запуск,
  перезапуск, события и итоги, миссия-заглушка `lobby`, разбор миссий `adopt`.
* Шаблон миссии и пример `op_north`.
* Рантайм 0.1.0: `sortied`, `sortie` (`install`, `doctor`, `status`, `events`,
  `top`) и мост для DCS 2.9.31.

Тесты без DCS появятся в SDK 0.2.
