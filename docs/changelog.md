# Что нового

Здесь — главное в каждой версии SDK. Полная история изменений, и что в каждой версии меняется
для уже написанной логики, — в
[CHANGELOG.md](https://github.com/lynxr/sortie-sdk/blob/v0.4.0/CHANGELOG.md) репозитория
SDK.

## 0.4.0

Ревизия API 3 и ревизия событий 2. В живой DCS ничего из этого ещё не проверялось.

* Метки F10 больше не останавливают часы сессии и таймеры.
* Спавн при старте миссии: пока в сессии нет игроков, спавны ограничивает бюджет моста в DCS, а
  не 2 группы в секунду. Ожидание у ворот спавна не съедает срок команды.
* Время DCS оплачивают два бюджета писателя: чтения и тяжёлые вызовы. Отказ по лимиту называет
  лимит и когда повторить: `e.limit()`, `e.retry_after()` ([Отказ по
  лимиту](dcs.md#отказ-по-лимиту)).
* `ctx.spawn_group(..).at_formation(точка, курс)` поворачивает строй шаблона целиком; наземный
  шаблон задаёт генератор, `sc.ground_template(..)` ([Группа из шаблона в
  точке](objects.md#группа-из-шаблона-в-точке)).
* Web API движка: HTTP/JSON для сайта сервера, документы и действия логики ([Web
  API](web-api.md)).
* Аэродромы и склады: владелец, автозахват и радиомолчание баз, событие смены владельца,
  стоянки и полосы, запас складов и его изменение, имена предметов DCS
  ([Аэродромы](airbases.md), [Склады](warehouses.md)).
* Наземные группы: `push_task` и `set_task`, маршрут `Task::ground_route(..)`, путь по дорогам и
  его сводка ([Задачи наземных и морских групп](sdk.md#задачи-наземных-и-морских-групп), [Путь
  по дорогам](dcs.md#путь-по-дорогам)).
* Генератор перечисляет Lua миссии вне Sortie; что с ним делать, задаёт
  `Scenario(do_scripts=..)` ([Генератор](generator.md)).

## 0.3.0

Ревизия API 2: поиск объектов в объёме — `ctx.search_objects(..)` ([Поиск
объектов](objects.md#поиск-объектов)).

## 0.2.1

Предмет склада можно назвать wsType, а не только именем.

## 0.2.0

Основа широкого API (ревизия API 1): каталог вызовов DCS и типизированные обёртки, статики и
пакеты спавнов, рисунки на карте, деревья меню F10, возможности движка.

## 0.1.0

Первый выпуск SDK: крейты `sortie` и `sortie-build`, генератор `sortie-gen`, шаблон миссии,
пример `op_north` и рантайм (`sortied`, `sortie`, мост для DCS).

## Чего пока нет

Тестов логики без DCS: FakeDcs содержит движок и в публичный SDK пока не входит. Логику
проверяют на живой DCS с `sortied --dev` ([Тестирование](testing.md)).
